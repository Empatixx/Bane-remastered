Skipped classes in cz.empatix.player and why
=============================================

ActiveUpgradeService
  - Its no-arg constructor hard-instantiates `new FileUpgradeService()` and immediately calls
    load() with NO injection seam. FileUpgradeService.load():
      * touches the real filesystem (Path.of("upgrades.bin"), Files.exists/readAllBytes, and
        createFile()->save() WRITES a file into the working directory), and
      * runs CryptoService (AES key/decrypt) on the bytes.
  - There is no way to construct ActiveUpgradeService headlessly without those filesystem side
    effects, and isBought() simply delegates to the loaded map (boughtUpgrades.get(name)), so the
    only "logic" is the map lookup which cannot be exercised without first triggering the file I/O.
  - Per rule 3, skipped to avoid filesystem side effects and non-deterministic crypto/file state.
    FileUpgradeService itself already has its own test package (app/src/test/.../upgrades/service).
