Bane je 2D top-down roguelike střílečka. Hráč je pokusný subjekt, kterého Vědec posílá portálem
do **Bane** — rány ve světě, jejíž patra se po každém sestupu přeskládají.

Tahle wiki popisuje **Rust port** (`rust/app`, hecs ECS + rapier2d + wgpu) na větvi `master`.
Java kód (`app/`, `game-engine-*`) je legacy a zdrojem pravdy není.

<Callout type="info">
Každá stránka má stejnou strukturu: **Jak to funguje** → **Obsah** (seznam všeho, co ve hře existuje)
→ **Interakce** → **Kde v kódu** → **Jak přidat nový …** → **Nápady / chybí**.
Sekce „Nápady / chybí“ je místo, kde hledat, co dodělat.
</Callout>
