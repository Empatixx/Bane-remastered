## Jak to funguje

### Sestavení a spuštění

Vše se spouští ze složky `rust/`:

```bash
cd rust
cargo run                 # debug build a spuštění
cargo run --release       # optimalizovaný build
cargo test                # všechny testy (zhruba 800 #[test])
cargo test print_module_cycles -- --ignored --nocapture   # report cyklů modulů
cargo clippy              # lint (workspace lints níže)
BANE_SEED=123456 cargo run   # přehrání konkrétního běhu
```

- Profil `dev` má `opt-level = 1` pro vlastní crate a `opt-level = 3` pro všechny závislosti — debug build je hratelný (rapier/wgpu jsou optimalizované).
- Workspace lints: `missing_debug_implementations` a `unreachable_pub` (rustc) a `clippy::unwrap_used` — všechno jako warning. Proto kód všude používá `pub(crate)` a místo `unwrap` vzory `let Some(..) else`.
- Testy jsou v `#[cfg(test)] mod tests` v každém souboru; běží bez okna a GPU (`Textures::default()`, `Audio::silent()`, `Settings::in_memory()`, `SharedProfile::in_memory()`). Shadery validuje `naga` (dev-závislost).

### Proměnné prostředí

| Proměnná | Účinek | Kde |
|---|---|---|
| `BANE_ASSETS` | cesta ke složce assetů (jinak hledá `assets/` nad binárkou) | `storage.rs` |
| `BANE_DATA` | složka pro `settings.json` a `profile.json` | `storage.rs` |
| `BANE_SEED` | seed běhu pro replay | `rng.rs` |

### Uložená data

- Složka dat: `BANE_DATA`, jinak systémová složka z `directories::ProjectDirs("cz", "empatix", "Bane")` (na macOS `~/Library/Application Support/cz.empatix.Bane`). Starý soubor se stejným jménem v pracovní složce se při prvním startu zkopíruje dovnitř (`adopt_legacy_file`).
- `settings.json` — `GameSettings` (camelCase JSON): `resolutionWidth`/`Height` (výchozí 1920 × 1080), `fullscreen` (false), `vsync` (true), `overallVolume` (1.0), `musicVolume` (0.5), `effectsVolume` (0.5), `controls` (rozložení kláves). Hodnoty se při načtení sanitizují (nulové rozlišení → výchozí, hlasitosti 0–1). Poškozený soubor → výchozí; nečitelný → výchozí a nic se neukládá.
- `profile.json` — trvalý postup (měna, upgrady, stromy zbraní, mise, výzvy), verze `PROFILE_VERSION = 1`; podrobnosti v [Uložení](/docs/progression/saves).

### Změny nastavení

Menu nastavení upravuje `pending` kopii; po potvrzení `Settings` vyprodukuje `Change` události:
- `Volume` → `Audio::set_volume`, `Controls` → `Input::set_bindings` (zpracuje `Game`),
- `Fullscreen` (borderless), `Resolution`, `Vsync` → okno a `Gpu` (zpracuje `app.rs` → `apply_changes`).

Nabídka rozlišení se bere z video módů monitoru, záložně 960 × 540, 1280 × 720, 1600 × 900, 1920 × 1080.

### Výkon

- `PerfCounter` (`perf.rs`) počítá snímky (`RedrawRequested`) a pevné kroky; jednou za sekundu zaloguje `performance fps=… ups=…` (úroveň info, na stdout přes neblokující `tracing_appender`).
- Ochrany: strop snímku 250 ms, rozpočet quadů s ořezem scény, max 64 světel, lightmapa v polovičním rozlišení, culling entit mimo obrazovku, okno zakryté → render spí 16 ms.

## Obsah

**Akce ovládání** (`controls::Action`, přemapovatelné v nastavení): `MoveUp`, `MoveDown`, `MoveLeft`, `MoveRight`, `Interact`, `Reload`, `UseArtefact`, `DropGun`, `Map`, `Dodge`. Střelba je na myši.

## Kde v kódu

- `main.rs` — `tracing_subscriber::fmt`, `EventLoop`
- `app.rs` → `apply_changes`, `monitor_resolutions`, `SETTINGS_FILE`, `PROFILE_FILE`
- `settings.rs` → `GameSettings`, `Settings`, `Change`, `FALLBACK_RESOLUTIONS`
- `storage.rs` → `data_file`, `assets_root`, `load_json`, `Loaded`
- `profile.rs` → `Profile`, `SharedProfile`, `PROFILE_VERSION`
- `perf.rs` → `PerfCounter`
- `controls.rs` → `Action`, `Bindings`
- `rust/Cargo.toml` — workspace, lints, profily

## Jak přidat nové nastavení

1. Pole do `GameSettings` s `#[serde(default)]` (aby staré `settings.json` šly načíst) a hodnota v `Default`.
2. Případná sanitizace v `GameSettings::sanitized`.
3. Nová varianta `Change` a její vyprodukování v `Settings` při potvrzení.
4. Zpracování: herní věci v `Game::take_setting_changes`, okenní/GPU v `app.rs` → `apply_changes`.
5. UI prvek v `scenes/settings_panel.rs` + komponenty v `components/settings_ui.rs`.

## Nápady / chybí

- FPS/UPS se jen logují; chybí in-game overlay (např. přepínač F3) s FPS, počtem entit, těl, quadů a světel.
- Logování nemá filtr (`RUST_LOG` se neuplatní, `tracing-subscriber` je bez funkce `env-filter`).
- `rust/README.md` obsahuje jen `cargo run` a zastaralý „plánovaný stack“ — chybí popis testů, proměnných prostředí a balení (`Resources/assets` naznačuje macOS bundle, ale skript na balení v repu není).
- Žádné nastavení kvality (počet světel, rozlišení lightmapy, vypnutí postfx) pro slabší stroje.
- Žádné CI konfigurace v repu (testy, clippy) — nalezeno nebylo.
