Hra běží v Rust portu v `rust/` (crate `bane`, jediný člen workspace `rust/app`). Java kód v repozitáři je jen historický zdroj; tato sekce popisuje výhradně Rust.

## Jak to funguje

**Stack (z `rust/app/Cargo.toml`):**

| Oblast | Knihovna | Kde |
|---|---|---|
| Okno, vstup, event loop | `winit` 0.30 | `main.rs`, `app.rs`, `input.rs` |
| Grafika | `wgpu` 30, shadery ve WGSL | `render/` |
| ECS | `hecs` 0.11 | `components/`, `systems/`, `prefabs/` |
| Fyzika | `rapier2d` 0.36 | `physics/` |
| Zvuk | `kira` 0.12 | `audio/` |
| Matematika | `glam` | všude |
| Fonty | `fontdue` | `render/font.rs` |
| Obrázky | `image` (TGA, PNG) | `render/texture.rs` |
| Uložení | `serde`, `serde_json`, `directories` | `storage.rs`, `settings.rs`, `profile.rs` |
| Logování | `tracing`, `tracing-subscriber`, `tracing-appender` | `main.rs` |
| Šum (generování) | `noise` | dungeon |

**Hlavní tok jednoho snímku (slovy):**

1. `main.rs` založí logování a `winit` event loop v režimu `Poll`, spustí `app::App`.
2. `App::resumed` vytvoří okno, `Gpu`, `Assets` a `Loader`, načte `settings.json` a `profile.json`, postaví `Game`.
3. `App::about_to_wait` každý průchod: krok načítání assetů (dokud `Loader` neskončí), aplikace změn nastavení, pak **pevný krok 60 UPS** (`Game::fixed_update`) tolikrát, kolik se nastřádalo času, nastavení `blend` pro interpolaci a jedna **proměnná aktualizace** (`Game::update`).
4. `WindowEvent::RedrawRequested` → `Game::frame()` posbírá vykreslovací vrstvy, světla a postprocessing a `Gpu::render` je vykreslí.
5. `Game` drží `Scenes` (stavový automat Loading → Menu → Lobby → InGame), `Audio`, `PostFx`, `Input` a `Settings`.

**Vrstvy modulů** (směr závislostí, hlídaný testem v `architecture.rs`):
`scenes` → `systems` → `prefabs` → `components` → doménové moduly (`guns`, `enemies`, `items`, `dungeon`, `artefacts`, `upgrades`, …) → `assets` → listové moduly (`clip`, `sheets`, `palette`, `viewport`).

## Interakce

- Všechny herní systémy (zbraně, nepřátelé, artefakty, dungeon) jsou ECS systémy volané ze scény `InGame` — viz [Architektura](/docs/tech/architektura).
- Obsah ostatních témat ([zbraně](/docs/guns), [nepřátelé](/docs/enemies), [artefakty a předměty](/docs/artefacts-items), [hráč](/docs/player), [dungeon](/docs/dungeon), [progrese](/docs/progression)) potřebuje textury a zvuky registrované podle stránek [Assety](/docs/tech/assety) a [Zvuk](/docs/tech/zvuk).

## Kde v kódu

- `main.rs` — seznam modulů, start event loopu.
- `app.rs` → `App` (okno, GPU, pevný krok `STEP`, `MAX_FRAME`).
- `game.rs` → `Game` (spojuje scény, audio, postfx, kurzor).
- `scenes/machine.rs` → `Scenes` (přepínání scén, hudba).
- `architecture.rs` — test proti cyklům mezi moduly.
