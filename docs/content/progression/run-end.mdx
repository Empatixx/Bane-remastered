---
title: End of run and victory
description: How a run ends, what the Game Over / Victory screen shows and how much gold you get for a run.
---

Whether a run ends in death, giving up (**Die** or **Main Menu** in the pause menu) or victory, the same screen with
stats always follows. This is where your **gold** is added, **missions** advance and the selected **challenge** is evaluated.

## How it works

### When the screen appears

- Health drops to 0 → **Game Over**.
- You choose **Die** in the pause menu → **Game Over** (with all rewards, as with a normal death).
- You choose **Main Menu** in the pause menu → also **Game Over** with all rewards, except that after a key press you go to the main menu instead of the lab.
- You defeat the boss on floor 5 → **Victory!**

At that moment the game stops (enemies and projectiles no longer move), artefact effects end and the large map closes.

### How the screen plays out

| Time | What you see |
|---|---|
| 0–1 s | The screen darkens (to 70%) |
| 0–2.5 s | A skull slides down from the top |
| from 2.5 s | The text **"Game Over"** or **"Victory!"** |
| 2.5–4.5 s | Four rows of stats slide in one by one (each takes half a second) |
| 4.5–6.5 s | The gold reward "loads" for each row |
| from 6.5 s | "Press any key to continue..." blinks, with a note about missions / challenge |
| key | Fade out and return to the lab (to the main menu after **Main Menu** from the pause menu) |

The note at the bottom reads for example *"Horde complete! +4 talents   2 missions ready on the board"*.

### Gold reward

Each row gives its own reward, which grows with the floor reached (roughly linearly: on floor 3 the
reward is about three times that of floor 1).

| Row | What it shows | Reward |
|---|---|---|
| **Accuracy** | Accuracy in % (hits / shots) | ≈ 2 × floor × accuracy in %; you get the full reward only from 50 shots, fewer shots reduce the reward proportionally |
| **Kills** | Number of enemies killed | ≈ 2 × floor × kills |
| **Loot** | Number of items picked up | ≈ 4 × floor × items |
| **Floor** | Floor reached | (floor − 1) × 5 |

The sum of all four rows is added to your gold.

**Example:** floor 3, accuracy 50%, 30 kills, 5 items → roughly 319 + 190 + 62 + 10 ≈ **581 gold**.

### Death vs. victory

| | Death | Victory |
|---|---|---|
| Text | Game Over | Victory! |
| Profile stat | +1 death | +1 win |
| Challenge with the goal "defeat the last boss" | not completed | completed |
| Other challenges | completed if you reached the target floor | completed |

## Contents

The screen contains: the darkening, a skull, the text, four rows with icons (accuracy, kills, loot, floor),
four rewards, the "Press any key" prompt and a note about progress.

## Tips and connections

- You spend gold at the [Weapon table](/docs/guns); talents at the Scientist — see [Currencies](/docs/progression/currencies).
- Mission and challenge progress: [Missions](/docs/progression/missions), [Challenges](/docs/progression/challenges).
- Accuracy is the most profitable row — shooting at walls and air does not pay off.
- Coins from the run are **not converted** to gold; they are lost.

## Known inconsistencies

- The Victory screen is the same as Game Over, just with a different text.
- The artefact chest after the last boss cannot be opened, because the Victory screen comes up immediately.

## Ideas for expansion

- A story line under the text ("Subject 41. Attempt N. Recorded." / "The wound is open.") and a different tone for victory.
- Converting some of the unused coins to gold.
- A short delay or a portal back after victory, so the last chest can be opened.
- A summary of the whole run (weapons, artefacts, time, seed) — also for sharing the seed with others.
