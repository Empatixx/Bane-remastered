Mise jsou hlavní zdroj **talentů**. Na Quest boardu v laboratoři (záložka **Tasks**) visí vždy tři,
každá jiného druhu. Plní se postupně během runů a po splnění si odměnu vyzvedneš kliknutím na lístek.

## Jak to funguje

- Na boardu jsou vždy **3 mise**, žádné dvě stejného druhu.
- Postup se nepočítá během runu, ale až **na jeho konci** — podle statistik runu a dosaženého patra.
- Mise se počítají dvěma způsoby:
  - **součtově** — postup se sčítá přes všechny runy (zabití, bossové, coins celkem, předměty, patra bez zásahu),
  - **nejlepší run** — počítá se jen nejlepší jednotlivý run (dosažené patro, coins v jednom runu).
- Splněnou misi **vyzvedneš kliknutím** na lístek → talenty se připíšou a na její místo se hned vylosuje nová (jiného druhu než zbylé dvě).
- Když v runu nějakou misi splníš, obrazovka konce runu ukáže „1 mission ready on the board“ / „N missions ready on the board“.
- Většina druhů má **3 stupně** obtížnosti; těžší stupeň = vyšší cíl a víc talentů (1 / 2 / 3).
- Pořadí losování je pevně dané pro tvůj profil — restart hry ti mise nepřelosuje.

## Obsah

| Mise | Popis ve hře | Cíl (stupeň 1 / 2 / 3) | Odměna (talenty) | Počítání |
|---|---|---|---|---|
| Crypt Cleaner | Defeat N enemies | 50 / 120 / 250 | 1 / 2 / 3 | součet |
| *nepřítel* Hunter (např. „rats Hunter“) | Defeat N rats / bats / slimes / ghosts / snakes | 10 / 25 / 50 | 1 / 2 / 3 | součet zabití daného druhu |
| *boss* Slayer | Defeat the *boss* | 1 | **2** | součet zabití daného bosse |
| Deep Delver | Reach floor N | 2 / 3 / 4 | 1 / 2 / 3 | nejlepší run |
| Gold Digger | Collect N coins in a single run | 40 / 80 / 140 | 1 / 2 / 3 | nejlepší run |
| Hoarder | Collect N coins | 150 / 300 / 600 | 1 / 2 / 3 | součet |
| Scavenger | Pick up N items | 15 / 30 / 60 | 1 / 2 / 3 | součet |
| Untouchable | Clear N floors without taking damage | 1 / 2 / 3 | 1 / 2 / 3 | součet pater bez zásahu |

**Lovení nepřátelé** pro misi Hunter: krysy (rats), netopýři (bats), slizy (slimes), duchové (ghosts), hadi (snakes).

**Bossové pro misi Slayer:** každý biom má právě jednoho bosse, takže boss čeká na patře se svým biomem:

| Boss | Biom |
|---|---|
| Spider king | Spider |
| Stone golem | Stone |
| Sewer ogre | Sewer |
| King slime | Moss |
| Argus | Ice |
| Hellhound | Lava |
| Mimic | Temple |

Run projde pěti ze sedmi biomů, takže hledaný boss se v jednom runu objeví zhruba s pravděpodobností 5 : 7.

„Coins“ v misích Gold Digger a Hoarder jsou mince sebrané v dungeonu, ne gold.

## Tipy a souvislosti

- Vyzvedávání: [Quest board](/docs/progression/quest-board). Utrácení talentů: [Měny](/docs/progression/currencies).
- Nepřátelé a bossové: [Nepřátelé](/docs/enemies).
- **Untouchable:** patro se započítá, až když z něj sejdeš žebříkem (nebo vyhraješ). Patro, na kterém zemřeš, se nepočítá — ani když tě na něm nic nezasáhlo.
- Gold Digger a Hoarder počítají sebrané coins, ne zůstatek — utrácením v obchodě o postup nepřijdeš.

## Známé nesrovnalosti

- Název mise na lov nepřátel začíná malým písmenem a v množném čísle („rats Hunter“ místo „Rat Hunter“).
- Mise na bosse závisí na náhodě: biomy pater se v každém runu náhodně zamíchají a run projde jen pěti ze sedmi, takže hledaného bosse v některém runu vůbec nepotkáš.

## Nápady na rozšíření

- U mise na bosse ukázat, ve kterém biomu se vyskytuje.
- Přelosování mise za talenty nebo gold.
- Vědcova poznámka pod každou misí (např. u Crypt Cleaner: „Fewer of them, more of you.“).
- Další druhy misí: zabij N nepřátel jednou zbraní, vyčisti místnost bez střelby, použij artefakt N×, otevři N truhel, vyhraj na slot machine, poraz bosse bez zásahu, dojdi na patro X v biomu Y.
