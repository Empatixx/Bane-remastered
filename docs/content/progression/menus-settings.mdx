The main menu is the first thing you see after loading. From here you go to the lab. The pause menu (Esc) works
in the lab and in the dungeon, and you open settings from the main menu and from the pause menu.

## How it works

### Main menu

- **Background:** a live crypt with an altar — an angel statue, a pentagram, five candelabras, books, chains, torches, bones, cobwebs, stones and crates, floating dust and a dark purple tint.
- The camera slowly moves and sways (one pass takes about 2.5 minutes).
- **Animals:** the first after 2.5 s, then every 5–11 s a rat or a bat runs across the screen.
- The **logo** flies up from the loading screen, then bobs, glows and now and then a shine sweeps across it.
- Once the logo lands, the buttons appear within less than half a second.
- The main menu music plays.

| Button | What it does |
|---|---|
| **Play** | Goes to the lab |
| **Settings** | Opens settings |
| **Exit** | Quits the game |

### Pause

**Esc** pauses the game: the background is blurred and everything stops.

| Where | Buttons |
|---|---|
| Lab | Resume · Settings · Main Menu · Exit Game |
| Dungeon | Resume · Settings · **Main Menu** · **Die** · Exit Game |

In the dungeon, Esc first closes the large map (Tab) and only then opens the pause menu.

- **Settings** opens the same settings as in the main menu. The game stays paused; Esc or the
  **Exit** button returns you to the pause menu. You can remap keys from here too.
- **Die** ends the run immediately, as if you had died — with all rewards — and then you return to the lab.
- **Main Menu** in the dungeon ends the run exactly like **Die** (stats, gold, missions and challenge
  are counted and the end-of-run screen is shown), except that afterwards you end up in the main menu instead of the lab.

See [End of run](/docs/progression/run-end).

### Settings

The panel has three tabs (Video, Audio, Controls) and three buttons:

- **Apply** — the changes take effect and are saved.
- **Revert** — reverts unsaved changes.
- **Exit** — closes the panel; unsaved changes are discarded. If you opened settings from the pause menu, you go back to it
  (just like with the Esc key; when a field is waiting for a new key, Esc only cancels the wait).

## Contents

### Settings items

| Tab | Item | Control | Default |
|---|---|---|---|
| Video | Resolution | left / right arrows | 1920 × 1080 |
| Video | V-sync | checkbox | on |
| Video | Fullscreen | checkbox | off |
| Audio | Overall | slider 0–100% | 100% |
| Audio | Music | slider 0–100% | 50% |
| Audio | Effects | slider 0–100% | 50% |
| Controls | 10 actions | click a field, then press a key | see below |

The list of resolutions is taken from your monitor; if the game cannot detect it, it offers 960 × 540, 1280 × 720,
1600 × 900 and 1920 × 1080.

### Controls

| Action | Default key |
|---|---|
| Move up / down / left / right | W / S / A / D |
| Interact | E |
| Reload | R |
| Use artefact | F |
| Drop weapon | Q |
| Map | Tab |
| Dodge | Space |
| Shoot | mouse (cannot be changed) |
| Pause | Esc (cannot be changed) |

You can assign the letters A–Z, arrows, Space, Tab, Enter, left Shift, Ctrl and Alt (36 keys in total). When you choose a key that is already
used by another action, they **swap** — the other action gets your original key.
