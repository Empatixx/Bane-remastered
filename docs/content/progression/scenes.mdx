---
title: Game screens and transitions
description: Which screens the game has (loading, menu, lab, dungeon), how you move between them and what music plays where.
---

The game has four main screens: **loading → main menu → lab → dungeon**. On the first launch, the [training crypt](/docs/progression/training) comes before the lab. The pause menu, settings,
the end-of-run screen and the station panels in the lab are not separate places — they open as a window
over the screen currently being played.

## How it works

### How to get where

| From | To | How |
|---|---|---|
| Loading | Main menu | Automatically after loading (a short half-second pause) |
| Main menu | Intro cinematic | The **Play** button, until you finish or skip training |
| Intro cinematic | Training crypt | By itself after 68 s with a fade to black, or Esc / space / Enter |
| Main menu | Lab | The **Play** button (after training) |
| Training crypt | Lab | The portal in the last room, or Esc → **Skip Training** |
| Lab | Training crypt | The book with the Training sign (E) |
| Main menu | Quit the game | The **Exit** button |
| Lab | Dungeon (new run) | The Interact key (**E** by default) at the portal |
| Lab | Main menu | Esc → **Main Menu** |
| Dungeon | Main menu | Esc → **Main Menu**: the run ends as a death, and after the end-of-run screen you go to the menu |
| Lab / dungeon | Quit the game | Esc → **Exit Game** |
| Dungeon | Next floor | The Interact key (**E** by default) at the ladder after defeating the boss |
| Dungeon | Lab | After the Game Over / Victory screen, any key; the screen fades out (under a second) |

### Music

| Screen | Music |
|---|---|
| Loading | silence |
| Main menu | the main menu theme |
| Lab | calm lab music |
| Dungeon | game music; in the boss room it switches to boss music, and back after the boss dies |

### Loading

A night sky, the animated Bane title and a spinning icon. Once the game is ready, it moves on to the main menu
after half a second (the title smoothly flies to its place in the menu).

## Contents

| Screen | What you do here | Controls | Details |
|---|---|---|---|
| Loading | You wait | — | above |
| Main menu | Start the game, open settings, leave | mouse | [Menus, pause, settings](/docs/progression/menus-settings) |

## Tips and connections

- You can open settings from the main menu and from the pause menu (Esc → **Settings**) — you can change the volume or keys without leaving the run.
- What gets saved during transitions: [What the game remembers](/docs/progression/saves).

## Known inconsistencies

- You cannot leave the dungeon for the lab without ending the run — a run in progress cannot be saved and finished later.
