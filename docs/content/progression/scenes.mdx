title: Herní obrazovky a přechody
description: Jaké obrazovky ve hře jsou (načítání, menu, laboratoř, dungeon), jak se mezi nimi pohybuješ a jaká hudba kde hraje.
---

Hra má čtyři hlavní obrazovky: **načítání → hlavní menu → laboratoř → dungeon**. Pauza, nastavení,
obrazovka konce runu a panely stanic v laboratoři nejsou samostatná místa — otevírají se jako okno
přes právě hranou obrazovku.

## Jak to funguje

### Kudy se kam dostaneš

| Odkud | Kam | Jak |
|---|---|---|
| Načítání | Hlavní menu | Automaticky po načtení (krátká půlsekundová pauza) |
| Hlavní menu | Laboratoř | Tlačítko **Play** |
| Hlavní menu | Konec hry | Tlačítko **Exit** |
| Laboratoř | Dungeon (nový run) | Klávesa Interakce (výchozí **E**) u portálu |
| Laboratoř | Hlavní menu | Esc → **Main Menu** |
| Dungeon | Hlavní menu | Esc → **Main Menu**: run skončí jako smrt, po obrazovce konce runu jdeš do menu |
| Laboratoř / dungeon | Konec hry | Esc → **Exit Game** |
| Dungeon | Další patro | Klávesa Interakce (výchozí **E**) u žebříku po poražení bosse |
| Dungeon | Laboratoř | Po obrazovce Game Over / Victory libovolná klávesa, obraz se zatemní (necelá sekunda) |

### Hudba

| Obrazovka | Hudba |
|---|---|
| Načítání | ticho |
| Hlavní menu | téma hlavního menu |
| Laboratoř | klidná hudba laboratoře |
| Dungeon | herní hudba; v místnosti s bossem se přepne na boss hudbu, po jeho smrti zpět |

### Načítání

Noční obloha, animovaný titulek Bane a točící se ikonka. Jakmile je hra připravená, po půl sekundě
přejde do hlavního menu (titulek plynule odletí na své místo v menu).

## Obsah

| Obrazovka | Co tu děláš | Ovládání | Podrobně |
|---|---|---|---|
| Načítání | Čekáš | — | výše |
| Hlavní menu | Spustíš hru, nastavení, odejdeš | myš | [Menu, pauza, nastavení](/docs/progression/menus-settings) |
| Laboratoř | Chodíš, utrácíš měny, volíš challenge, vstupuješ do portálu | pohyb + E, kurzor myši | [Laboratoř](/docs/progression/lobby) |
| Dungeon | Hraješ run | pohyb, střelba, kurzor se mění na zaměřovač (a ukazuje přebíjení) | [Průběh runu](/docs/progression/run) |

## Tipy a souvislosti

- Nastavení otevřeš z hlavního menu i z pauzy (Esc → **Settings**) — hlasitost nebo klávesy si změníš, aniž bys opouštěl run.
- Co se při přechodech ukládá: [Co si hra pamatuje](/docs/progression/saves).

## Známé nesrovnalosti

- Z dungeonu se nedá odejít do laboratoře bez ukončení runu — rozehraný run nejde uložit a dohrát později.

## Nápady na rozšíření

- Epilog / pravý konec po splnění challenge Bane (viz [Příběh](/docs/progression/story)).
- Obrazovka profilu se statistikami a credits.
