---
title: What the game remembers
description: What stays saved between runs and after the game is turned off — currencies, talents, weapon upgrades, missions, challenges, stats and settings.
---

Bane saves continuously and automatically, no manual saving is needed. You have one **profile** and one
**settings** file. A run in progress is not saved, though — if you turn the game off during a run, the run is lost.

## How it works

- The **profile** is saved every time something in it changes: buying a talent or a weapon upgrade, the end of a run,
  claiming a mission, selecting a challenge.
- **Settings** are saved when you press **Apply** in them.
- Saving is safe: even if the game crashes in the middle of a write, the old state stays whole.
- When the saved data gets damaged, the game sets the damaged file aside as a backup and starts with a clean profile — so you do not lose the original data completely.
- If a new version of the game removes or renames a talent, weapon, mission or challenge, only that one item disappears from the profile; the rest stays. Missing missions are filled in with new ones.
- When the shape of the weapon upgrade trees changes, the old trees are reset and the gold spent is returned.

## Contents

### What is remembered between runs

| What | Note |
|---|---|
| **Talents** to spend | [Currencies](/docs/progression/currencies) |
| **Gold** to spend and total gold earned | [Currencies](/docs/progression/currencies) |
| Bought talents | The talent tree at the Scientist |
| Upgrades of each weapon | Bought nodes, number of rerolls, gold spent — [Guns](/docs/guns) |
| Active missions and their progress | Including the roll order of new missions — [Missions](/docs/progression/missions) |
| The selected challenge and completed challenges | [Challenges](/docs/progression/challenges) |
| Profile stats | Number of runs, wins and deaths, kills, items picked up, shots and hits, deepest floor |
| Settings | Resolution, fullscreen, v-sync, volumes, controls — [Menus and settings](/docs/progression/menus-settings) |

### What is not remembered

| What | Note |
|---|---|
| A run in progress | Lost when the game is turned off |
| Coins | Lost at the end of every run |
| Weapons and artefacts from the run | You start every run anew |
| History of individual runs | Only summary numbers are saved |

## Tips and connections

- What gets written to the profile at the end of a run: [End of run](/docs/progression/run-end).
- You cannot see the saved profile stats anywhere in the game yet.

## Known inconsistencies

- Progress from the old Java version of the game does not carry over.

## Ideas for expansion

- "New game+" after the true ending, as the story envisions.
- Steam Cloud.
