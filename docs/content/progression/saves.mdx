Bane ukládá průběžně a automaticky, žádné ruční ukládání není potřeba. Máš jeden **profil** a jedno
**nastavení**. Rozehraný run se ale neukládá — když hru během runu vypneš, run je ztracený.

## Jak to funguje

- **Profil** se uloží pokaždé, když se v něm něco změní: nákup talentu nebo vylepšení zbraně, konec runu,
  vyzvednutí mise, výběr challenge.
- **Nastavení** se uloží, když v něm zmáčkneš **Apply**.
- Ukládání je bezpečné: i když hra spadne uprostřed zápisu, starý stav zůstane celý.
- Když se uložená data poškodí, hra si poškozený soubor odloží stranou jako zálohu a začne s čistým profilem — o původní data tedy nepřijdeš úplně.
- Pokud nová verze hry odebere nebo přejmenuje nějaký talent, zbraň, misi nebo challenge, zmizí z profilu jen ta jedna položka; zbytek zůstane. Chybějící mise se doplní nové.
- Když se změní podoba stromů vylepšení zbraní, staré stromy se vyresetují a utracený gold se vrátí.

## Obsah

### Co se pamatuje mezi runy

| Co | Poznámka |
|---|---|
| **Talenty** k utracení | [Měny](/docs/progression/currencies) |
| **Gold** k utracení a celkem vydělaný gold | [Měny](/docs/progression/currencies) |
| Koupené talenty | Talentový strom u Vědce |
| Vylepšení každé zbraně | Koupené uzly, počet rerollů, utracený gold — [Zbraně](/docs/guns) |
| Aktivní mise a jejich postup | Včetně pořadí losování nových misí — [Mise](/docs/progression/missions) |
| Vybraná challenge a splněné challenge | [Challenge](/docs/progression/challenges) |
| Statistiky profilu | Počet runů, výher a smrtí, zabití, sebrané předměty, výstřely a zásahy, nejhlubší patro |
| Nastavení | Rozlišení, fullscreen, v-sync, hlasitosti, ovládání — [Menu a nastavení](/docs/progression/menus-settings) |

### Co se nepamatuje

| Co | Poznámka |
|---|---|
| Rozehraný run | Vypnutím hry se ztratí |
| Coins | Propadnou na konci každého runu |
| Zbraně a artefakty z runu | Každý run začínáš znovu |
| Historie jednotlivých runů | Ukládají se jen souhrnná čísla |

## Tipy a souvislosti

- Co se do profilu zapisuje na konci runu: [Konec runu](/docs/progression/run-end).
- Uložené statistiky profilu zatím nikde ve hře neuvidíš.

## Známé nesrovnalosti

- Postup ze staré Java verze hry se nepřenáší.

## Nápady na rozšíření

- Víc profilů a možnost profil smazat / začít znovu přímo ve hře.
- „New game+“ po pravém konci, jak počítá příběh.
- Steam Cloud.
- Uložení rozehraného runu při vypnutí hry a historie runů (seed, výsledek, zbraně).
