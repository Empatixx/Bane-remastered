**Crossbow** je přesná zbraň na střední vzdálenost. Šipka ubere 5–7 a projde jedním nepřítelem.

## Jak to funguje

Poloautomatická zbraň bez rozptylu. Šipka letí rychle a má **průraz 1** — projde prvním nepřítelem a zastaví se ve druhém.

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na ránu | 5–7 (průměr 6) |
| Kadence | 1,7 rány/s |
| DPS | 10 |
| Režim | poloautomatická |
| Rozptyl | žádný |
| Zásobník / rezerva | 3 / 45 |
| Přebití | 1,0 s |
| Kritická šance | 0 % |
| Projektil | šipka, rychlá, oranžovočervené světlo |
| Průraz | 1 |
| Otřes obrazovky | slabý |
| Nábojnice | ne |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Malý zásobník (3) — uzly **Magazine** jsou tu relativně nejsilnější (+3 zásobník zdvojnásobí).
- Mutace **Piercing** zvedne průraz na 2. Viz [Mutace](/docs/guns/mutace).
- Strom kuše nenabízí uzly **Accuracy** — rozptyl už je nulový.

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 5–8, ale 8 nikdy nepadne.

## Nápady na rozšíření

- Šipky zabodnuté ve zdi, které jde sebrat zpátky (vrací munici).
- Šipky s jedem nebo ohněm jako vlastní varianty.
