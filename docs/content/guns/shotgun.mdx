**Shotgun** (`GunKind::Shotgun`) — Druhá startovní zbraň (slot 2). Jediná zbraň s vlastní třídou munice `AmmoClass::Shotgun`.

## Jak to funguje

### Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození v kódu | 3–5 |
| Reálné poškození na projektil | 3–4 (průměr 3,5) |
| Projektilů na výstřel | 4 |
| Kadence | 2 výstřelů/s |
| Průměrné DPS (bez přebíjení) | 28 |
| Odchylka (`inaccuracy`) | 0,1 (vějíř broků, viz níže) |
| Režim | poloautomatická |
| Zásobník / rezerva | 6 / 48 |
| Přebíjení | 0,7 s |
| Kritická šance (základ) | 0 % |
| Otřes kamery (`shake`) | 0,6 |
| Třída munice | `AmmoClass::Shotgun` |
| Styl zásobníku v HUD | `ClipStyle::Shotgun` — jeden sloupec brokových nábojů `SHOTGUN_AMMO_HUD` (krok 20 px) |
| Nábojnice | ano (brokový řádek sheetu) |
| Zvuk výstřelu / přebití | `ShotgunShoot` / `ShotgunReload` |
| Textura / velikost ikony | `tex::GUNS_SHOTGUN` / 96 × 36 px |
| Klíč v profilu | `"shotgun"` |

Hodnoty jsou základní (bez stromu zbraně a perků). U zbraní s rozsahem poškození je reálné maximum o 1 nižší než maximum v kódu, protože `GunSpec::damage_for` počítá `min + floor(roll × (max − min))` a `roll` je menší než 1 — viz [Střelba](/docs/guns/strelba).

### Střelba

Poloautomatická. Jeden náboj ze zásobníku vystřelí `MAX_PELLETS` = 4 broky. Broky se nerozptylují náhodně, ale **deterministickým vějířem**: broky 0–3 mají odchylku 0, −0,05, +0,1 a −0,15 rad (0°, −2,9°, +5,7°, −8,6°) — vzorec `0.5 × inaccuracy × index × (±1)`. Každý brok má vlastní hod poškození, ale kritický zásah se hází jednou pro celý výstřel.

Podrobnosti o všech typech projektilů: [Projektily](/docs/guns/projektily).

### Přebíjení a munice

Přebíjí se ručně klávesou R (`Action::Reload`). Přebití trvá 0,7 s, pak se zásobník doplní z rezervy (max. 6 nábojů). Rezervu 48 nábojů lze zvýšit perkem *Additional Ammo* (×1,1). Doplňují ji krabice `AmmoBox::Shotgun` a `AmmoBox::Universal`. Viz [Loadout a munice](/docs/guns/loadout).

### Zvláštnosti

- Vyhazuje nábojnici z druhého řádku sheetu (brokový náboj), protože `clip_style == ClipStyle::Shotgun`.
- Statistika `Stat::Fired` počítá broky, ne náboje — jeden výstřel = 4 vystřelené projektily.
- Munici doplňují jen krabice `AmmoBox::Shotgun` (+25 %) a `AmmoBox::Universal` (+50 %).
- Strom zbraně s uzlem Accuracy zužuje i vějíř (odchylka je násobek `inaccuracy`).

## Nápady / chybí

- Vějíř je asymetrický (víc doleva/doprava podle znaménka) — 4 broky nejdou symetricky kolem osy. Pro sudý počet broků by dávalo smysl ±0,025/±0,075.
- FEATURE.md stále uvádí poškození 222–333 (Java debug hodnota); Rust port má opraveno na 3–5. Dokumentaci FEATURE.md aktualizovat.
- S DPS 28 (všechny broky zasáhnou) je výrazně nejsilnější zbraní hry, přitom startovní. Balanc pass (TODO.md P0) stále otevřený.
