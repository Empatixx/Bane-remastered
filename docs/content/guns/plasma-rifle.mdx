**Plasma Rifle** je automat s plošným efektem: přes 6 ran za sekundu a každý zásah zraní i nepřátele okolo.

## Jak to funguje

Automatická zbraň — střílí, dokud hráč drží tlačítko. Zelené plazmové koule při dopadu (i o zeď) **cáknou**: všichni nepřátelé a rozbitné objekty v okolí cca 1,25 × 1,25 dlaždice dostanou polovinu poškození (nejméně 1). Přímo zasažený nepřítel dostane jen plnou ránu, cákanec ne.

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na ránu | 2 |
| Cákanec | 1 okolním cílům |
| Kadence | 6,25 rány/s |
| DPS (jeden cíl) | 12,5 |
| Režim | automatická |
| Rozptyl | ±3,4° |
| Zásobník / rezerva | 24 / 240 |
| Přebití | 1,4 s |
| Kritická šance | 0 % |
| Projektil | plazma, střední rychlost, zelené světlo |
| Průraz | 0 |
| Otřes obrazovky | velmi slabý |
| Nábojnice | ne |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Silná proti hloučkům nepřátel — i střela, která mine, může cáknout na nepřátele u zdi.
- Cákanec rozbíjí sudy a hrnce v okolí.
- Uzly **Damage** zvyšují i cákanec — od poškození 4 dává okolí 2.

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 2–3, ale 3 nikdy nepadne.
- Cákance se nepočítají jako zásahy do přesnosti ani do schopností, které počítají zásahy.

## Nápady na rozšíření

- Nabíjený výstřel — podržením větší koule s větším cákancem.
