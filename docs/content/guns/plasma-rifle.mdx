**Plasma Rifle** (`GunKind::PlasmaRifle`) — Automat s plošným efektem: 6,25 ran/s, zásah zraní i nepřátele kolem.

## Jak to funguje

### Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození v kódu | 2–3 |
| Reálné poškození na projektil | 2 (průměr 2) |
| Projektilů na výstřel | 1 |
| Kadence | 6,25 výstřelů/s |
| Průměrné DPS (bez přebíjení) | 12,5 |
| Odchylka (`inaccuracy`) | 0,12 → ±0,06 rad (±3,4°) |
| Režim | automatická |
| Zásobník / rezerva | 24 / 240 |
| Přebíjení | 1,4 s |
| Kritická šance (základ) | 0 % |
| Otřes kamery (`shake`) | 0,12 |
| Třída munice | `AmmoClass::Pistol` |
| Styl zásobníku v HUD | `ClipStyle::SubMachine` — dva sloupce nábojů (krok 15 px, sloupce po 25 px) |
| Nábojnice | ne |
| Zvuk výstřelu / přebití | `PlasmaShoot` / `PlasmaReload` |
| Textura / velikost ikony | `tex::GUNS_PLASMA_RIFLE` / 104 × 46 px |
| Klíč v profilu | `"plasma_rifle"` |

Hodnoty jsou základní (bez stromu zbraně a perků). U zbraní s rozsahem poškození je reálné maximum o 1 nižší než maximum v kódu, protože `GunSpec::damage_for` počítá `min + floor(roll × (max − min))` a `roll` je menší než 1 — viz [Střelba](/docs/guns/strelba).

### Střelba

Automatická, `Round::Plasma` (650 px/s, zelené světlo), odchylka ±0,06 rad (±3,4°).

### Projektil

| Vlastnost | Hodnota |
| --- | --- |
| Typ | `Round::Plasma` |
| Rychlost | 650 px/s |
| Velikost sprite / hitbox | 24 × 24 / 16 × 16 |
| Průraz (`pierce`) | 0 |
| Životnost | — |
| Zvláštní efekt | splash (poloviční poškození v 80 × 80) |
| Světlo | zelené (60, 255, 90) |
| Natáčí se ve směru letu | ne |
| Textura | `tex::ROUND_PLASMA` |

Podrobnosti o všech typech projektilů: [Projektily](/docs/guns/projektily).

### Přebíjení a munice

Přebíjí se ručně klávesou R (`Action::Reload`). Přebití trvá 1,4 s, pak se zásobník doplní z rezervy (max. 24 nábojů). Rezervu 240 nábojů lze zvýšit perkem *Additional Ammo* (×1,1). Doplňují ji krabice `AmmoBox::Pistol`, `AmmoBox::SubMachine` a `AmmoBox::Universal`. Viz [Loadout a munice](/docs/guns/loadout).

### Zvláštnosti

- `splash: true` — při zásahu (i o zeď) dostanou všichni nepřátelé a rozbitné objekty v oblasti 80 × 80 kolem místa dopadu poloviční poškození (min. 1), přímo zasažený nepřítel ne. Typ poškození `Explosion`.

## Interakce

- Vylepšení stromem zbraně ve stole v lobby: [Strom zbraně](/docs/guns/strom-zbrane).
- Mutace na konci stromu: [Mutace](/docs/guns/mutace).
- Získání: zbraňová truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani).
- Perky poškození a kritického zásahu z [progrese](/docs/progression) se násobí s hodnotami zbraně.

## Kde v kódu

- `guns.rs` → `GunKind::PlasmaRifle`, větev v `GunKind::spec`, `Round::Plasma` v `Round::spec`
- `systems/shooting.rs` → `shoot`, `bullet_hits`
- `scenes/weapon_table.rs` → `name` (zobrazované jméno „Plasma Rifle“)
- `assets.rs` → `tex::GUNS_PLASMA_RIFLE`
