**Minigun** je zbraň na nepřetržitou palbu: téměř 17 ran za sekundu, největší zásobník ve hře (40) a nejdelší přebíjení (2,2 s).

## Jak to funguje

Automatická zbraň — střílí, dokud hráč drží tlačítko. Střílí žluté stopovky, které letí rychleji než obyčejné kulky, s rozptylem kolem ±8,6°.

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na ránu | 1 |
| Kadence | 16,7 rány/s |
| DPS | 16,7 |
| Režim | automatická |
| Rozptyl | ±8,6° |
| Zásobník / rezerva | 40 / 400 |
| Přebití | 2,2 s |
| Kritická šance | 0 % |
| Projektil | stopovka, rychlá, žluté světlo |
| Průraz | 0 |
| Otřes obrazovky | velmi slabý na ránu, při držení znatelný |
| Nábojnice | ano |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Nejvyšší DPS po Shotgunu a navíc na libovolnou vzdálenost.
- Zásobník vydrží jen 2,4 s palby a přebíjení trvá 2,2 s — uzly **Reload** jsou nejcennější vylepšení.
- Ideální nosič mutace **Frost** — čtyři zásahy na zmrazení přijdou během čtvrt sekundy. Viz [Mutace](/docs/guns/mutace).
- Strom Minigunu nenabízí uzly **Magazine** — zásobník je už na maximu 40.
- Upgrady poškození od Scientista mu přidají bod navíc jen u části střel (se *Sharpened Bullets* u každé páté); víc ho posílí strom zbraně.

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 1–2, ale Minigun dává vždy 1.
- S uzly **Fire rate** se obrazovka při držení spouště třese téměř nepřetržitě.

## Nápady na rozšíření

- Roztáčení hlavně — kadence roste, jak hráč drží spoušť.
- Zpomalení hráče při střelbě jako protiváha síly.
