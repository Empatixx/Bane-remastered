**Railgun** (`GunKind::Railgun`) — Těžká precizní zbraň: 14–19 poškození, neomezený průraz, 3 náboje v zásobníku.

## Jak to funguje

### Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození v kódu | 14–20 |
| Reálné poškození na projektil | 14–19 (průměr 16,5) |
| Projektilů na výstřel | 1 |
| Kadence | 0,62 výstřelů/s |
| Průměrné DPS (bez přebíjení) | 10,31 |
| Odchylka (`inaccuracy`) | 0 (dokonale přesná) |
| Režim | poloautomatická |
| Zásobník / rezerva | 3 / 24 |
| Přebíjení | 2 s |
| Kritická šance (základ) | 0 % |
| Otřes kamery (`shake`) | 1 |
| Třída munice | `AmmoClass::Pistol` |
| Styl zásobníku v HUD | `ClipStyle::Shotgun` — jeden sloupec brokových nábojů `SHOTGUN_AMMO_HUD` (krok 20 px) |
| Nábojnice | ne |
| Zvuk výstřelu / přebití | `RailgunShoot` / `RailgunReload` |
| Textura / velikost ikony | `tex::GUNS_RAILGUN` / 132 × 40 px |
| Klíč v profilu | `"railgun"` |

Hodnoty jsou základní (bez stromu zbraně a perků). U zbraní s rozsahem poškození je reálné maximum o 1 nižší než maximum v kódu, protože `GunSpec::damage_for` počítá `min + floor(roll × (max − min))` a `roll` je menší než 1 — viz [Střelba](/docs/guns/strelba).

### Střelba

Poloautomatická, `Round::Rail` (1800 px/s, hitbox 24), bez rozptylu, `pierce: u32::MAX`.

Podrobnosti o všech typech projektilů: [Projektily](/docs/guns/projektily).

### Přebíjení a munice

Přebíjí se ručně klávesou R (`Action::Reload`). Přebití trvá 2 s, pak se zásobník doplní z rezervy (max. 3 nábojů). Rezervu 24 nábojů lze zvýšit perkem *Additional Ammo* (×1,1). Doplňují ji krabice `AmmoBox::Pistol`, `AmmoBox::SubMachine` a `AmmoBox::Universal`. Viz [Loadout a munice](/docs/guns/loadout).

### Zvláštnosti

- Mutace Piercing nic nepřidá (saturace).
- Accuracy uzly zbytečné.
- Shake 1,0 — druhý nejsilnější otřes po RPG.

## Interakce

- Vylepšení stromem zbraně ve stole v lobby: [Strom zbraně](/docs/guns/strom-zbrane).
- Mutace na konci stromu: [Mutace](/docs/guns/mutace).
- Získání: zbraňová truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani).
- Perky poškození a kritického zásahu z [progrese](/docs/progression) se násobí s hodnotami zbraně.

## Kde v kódu

- `guns.rs` → `GunKind::Railgun`, větev v `GunKind::spec`, `Round::Rail` v `Round::spec`
- `systems/shooting.rs` → `shoot`, `bullet_hits`
- `scenes/weapon_table.rs` → `name` (zobrazované jméno „Railgun“)
- `assets.rs` → `tex::GUNS_RAILGUN`

## Nápady / chybí

- Nabíjení (charge) před výstřelem by odlišilo Railgun od Sniperu.
- Vizuální paprsek přes celou dráhu místo projektilu.
