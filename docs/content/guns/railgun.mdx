**Railgun** je těžká precizní zbraň: každá rána ubere 14–19, letí nejrychleji ze všech střel a prolétne všemi nepřáteli v cestě. Za to má jen 3 náboje v zásobníku a dlouhé přebíjení.

## Jak to funguje

Poloautomatická zbraň bez rozptylu. Střela má větší zásahovou plochu než ostatní a **neomezený průraz** — zastaví ji až zeď.

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na ránu | 14–19 (průměr 16,5) |
| Kadence | 0,6 rány/s |
| DPS (jeden cíl) | 10,3 |
| Režim | poloautomatická |
| Rozptyl | žádný |
| Zásobník / rezerva | 3 / 24 |
| Přebití | 2,0 s |
| Kritická šance | 0 % |
| Projektil | rail, nejrychlejší, tyrkysové světlo |
| Průraz | neomezený |
| Otřes obrazovky | silný (druhý nejsilnější po RPG) |
| Nábojnice | ne |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Nejsilnější proti nepřátelům v řadě — v chodbě zasáhne všechny najednou.
- S artefaktem Phantom (první rána ze zálohy ×2) a kritickým zásahem dá jedna rána přes 70.
- Dobře se hodí k mutaci **Deadeye** a uzlům **Crit** — viz [Mutace](/docs/guns/mutace).
- Strom Railgunu nenabízí mutaci **Piercing** (střela už prochází vším) ani uzly **Accuracy** (rozptyl je nulový).
- Malá rezerva (24) — šetři ji na silné nepřátele a bosse.

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 14–20, ale 20 nikdy nepadne.
- Railgun může padnout hned v první truhle 1. patra.

## Nápady na rozšíření

- Nabíjení před výstřelem, které by odlišilo Railgun od Sniperu.
- Vizuální paprsek přes celou dráhu místo letící střely.
