**Tesla Gun** je zbraň na řetězové poškození. Modrá jiskra po zásahu přeskočí bleskem na další dva nepřátele a každý dostane plnou ránu.

## Jak to funguje

Poloautomatická zbraň s malým rozptylem (±2,9°). Jiskra letí střední rychlostí a nechává za sebou modré jiskřičky. Po zásahu nepřítele **přeskočí blesk dvakrát** — pokaždé na nejbližšího dosud nezasaženého nepřítele do cca 3,4 dlaždice od posledního cíle. Každý skok dává **plné** poškození a zapraská.

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na cíl | 3–4 (průměr 3,5) |
| Zasažených cílů | až 3 (zásah + 2 skoky) |
| Kadence | 1,8 rány/s |
| DPS (jeden cíl) | 6,4 |
| DPS (tři cíle) | až 19 |
| Režim | poloautomatická |
| Rozptyl | ±2,9° |
| Zásobník / rezerva | 8 / 80 |
| Přebití | 1,2 s |
| Kritická šance | 0 % |
| Projektil | jiskra, střední rychlost, modré světlo a stopa |
| Dosah skoku | cca 3,4 dlaždice |
| Otřes obrazovky | slabý |
| Nábojnice | ne |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Na jednoho nepřítele je slabá, proti skupině patří k nejsilnějším zbraním.
- Skoky blesku se počítají jako zásahy, takže nabíjí schopnosti, které počítají zásahy.
- Blesk nepřeskakuje na sudy a hrnce ani na nepřátele, kteří se teprve objevují.
- Artefakt **Thunder Idol** má vlastní, silnější řetězový blesk — viz [Artefakty a předměty](/docs/artefacts-items).

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 3–5, ale 5 nikdy nepadne.
- Blesk Tesly a blesk Thunder Idolu fungují každý jinak (jiný dosah, počet cílů i vzhled).

## Nápady na rozšíření

- Uzel stromu „+1 skok blesku“.
- Sjednotit vzhled s bleskem Thunder Idolu.
