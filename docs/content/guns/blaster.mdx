**Blaster** je sci-fi poloautomat. Na poloautomatickou zbraň střílí rychle (4,5 rány za sekundu), je přesný a každý laser ubere 2–3.

## Jak to funguje

Poloautomatická zbraň: jeden laser na kliknutí, rozptyl jen ±1,4°. Laser letí velmi rychle a za letu za sebou nechává červené světélkující částice.

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na ránu | 2–3 (průměr 2,5) |
| Kadence | 4,5 rány/s |
| DPS | 11,4 |
| Režim | poloautomatická |
| Rozptyl | ±1,4° |
| Zásobník / rezerva | 12 / 144 |
| Přebití | 1,0 s |
| Kritická šance | 0 % |
| Projektil | laser, velmi rychlý, červené světlo a stopa |
| Průraz | 0 |
| Otřes obrazovky | slabý |
| Nábojnice | ne |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Nejlepší poloautomat na DPS po Shotgunu — rychlý laser se snadno trefuje i na dálku.
- Kadence záleží na tom, jak rychle hráč kliká; uzly **Fire rate** pomůžou jen tehdy, když stíhá.

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 2–4, ale 4 nikdy nepadne.
- Laser se dobíjí krabicemi s obyčejnými náboji.

## Nápady na rozšíření

- Energetické zbraně (Blaster, Plasma Rifle, Tesla Gun, Railgun) by mohly mít vlastní munici nebo přehřívání místo zásobníku.
- Odraz laseru od zdí jako vlastní vlastnost.
