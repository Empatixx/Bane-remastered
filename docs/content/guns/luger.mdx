**Luger** (`GunKind::Luger`) — Alternativa k pistoli z truhly/obchodu. Větší zásobník (9) a rezerva (150), ale poškození reálně vždy 1.

## Jak to funguje

### Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození v kódu | 1–2 |
| Reálné poškození na projektil | 1 (průměr 1) |
| Projektilů na výstřel | 1 |
| Kadence | 4 výstřelů/s |
| Průměrné DPS (bez přebíjení) | 4 |
| Odchylka (`inaccuracy`) | 0,35 → ±0,17 rad (±10,0°) |
| Režim | poloautomatická |
| Zásobník / rezerva | 9 / 150 |
| Přebíjení | 0,7 s |
| Kritická šance (základ) | 0 % |
| Otřes kamery (`shake`) | 0,3 |
| Třída munice | `AmmoClass::Pistol` |
| Styl zásobníku v HUD | `ClipStyle::Pistol` — jeden sloupec nábojů (krok 15 px) |
| Nábojnice | ano (nábojnice) |
| Zvuk výstřelu / přebití | `PistolShoot` / `PistolReload` |
| Textura / velikost ikony | `tex::GUNS_LUGER` / 50 × 38 px |
| Klíč v profilu | `"luger"` |

Hodnoty jsou základní (bez stromu zbraně a perků). U zbraní s rozsahem poškození je reálné maximum o 1 nižší než maximum v kódu, protože `GunSpec::damage_for` počítá `min + floor(roll × (max − min))` a `roll` je menší než 1 — viz [Střelba](/docs/guns/strelba).

### Střelba

Poloautomatická, jedna kulka `Round::Bullet`, odchylka ±0,175 rad (±10°).

Podrobnosti o všech typech projektilů: [Projektily](/docs/guns/projektily).

### Přebíjení a munice

Přebíjí se ručně klávesou R (`Action::Reload`). Přebití trvá 0,7 s, pak se zásobník doplní z rezervy (max. 9 nábojů). Rezervu 150 nábojů lze zvýšit perkem *Additional Ammo* (×1,1). Doplňují ji krabice `AmmoBox::Pistol`, `AmmoBox::SubMachine` a `AmmoBox::Universal`. Viz [Loadout a munice](/docs/guns/loadout).

### Zvláštnosti

- Rozsah `1–2` znamená kvůli `damage_for` vždy přesně 1 poškození (maximum se nikdy nepadne).
- Sdílí zvuky s pistolí (`PistolShoot`, `PistolReload`).

## Kde v kódu

- `guns.rs` → `GunKind::Luger`, větev v `GunKind::spec`, `Round::Bullet` v `Round::spec`
- `systems/shooting.rs` → `shoot`, `bullet_hits`
- `scenes/weapon_table.rs` → `name` (zobrazované jméno „Luger“)
- `assets.rs` → `tex::GUNS_LUGER`

## Nápady / chybí

- Je to striktně horší pistole (DPS 4 vs. 6). Dát jí identitu — např. vyšší kritickou šanci nebo rychlejší kadenci.
- Vlastní zvuk výstřelu chybí.
