**Uzi** je automatická „stříkačka“: chrlí 10 ran za sekundu, ale každá ubere jen 1 a rány se hodně rozptylují.

## Jak to funguje

Automatická zbraň — střílí, dokud hráč drží tlačítko. Každá rána je obyčejná kulka s rozptylem až ±11,5°.

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na ránu | 1 |
| Kadence | 10 ran/s |
| DPS | 10 |
| Režim | automatická |
| Rozptyl | ±11,5° |
| Zásobník / rezerva | 20 / 200 |
| Přebití | 0,7 s |
| Kritická šance | 0 % |
| Projektil | kulka, střední rychlost, červené světlo |
| Průraz | 0 |
| Otřes obrazovky | velmi slabý na ránu, při držení znatelný |
| Nábojnice | ano |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Hodně ran = hodně příležitostí pro mutace, které spouští zásah: **Frost** zmrazí nepřítele za necelou půlsekundu, **Venom** a **Explosive** se spouští neustále. Viz [Mutace](/docs/guns/mutace).
- Upgrady poškození od Scientista jí přidají bod navíc jen u části ran (se *Sharpened Bullets* u každé páté); víc ji posílí strom zbraně.
- Zásobník 20 se vyprázdní za 2 sekundy — uzly **Magazine** a **Reload** se vyplatí.

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 1–2, ale Uzi dává vždy 1.
- S hodně uzly **Fire rate** se obrazovka při držení spouště třese téměř nepřetržitě.

## Nápady na rozšíření

- Akimbo varianta (dvě Uzi) jako uzel stromu nebo samostatná zbraň.
