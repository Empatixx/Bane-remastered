**Thompson** je automatická zbraň „do pohody“: 5 ran za sekundu, téměř žádný rozptyl a zásobník na 30 nábojů.

## Jak to funguje

Automatická zbraň — střílí, dokud hráč drží tlačítko. Obyčejné kulky letí skoro přesně tam, kam hráč míří (±1,4°).

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na ránu | 1–2 (průměr 1,5) |
| Kadence | 5 ran/s |
| DPS | 7,5 |
| Režim | automatická |
| Rozptyl | ±1,4° |
| Zásobník / rezerva | 30 / 300 |
| Přebití | 0,85 s |
| Kritická šance | 0 % |
| Projektil | kulka, střední rychlost, červené světlo |
| Průraz | 0 |
| Otřes obrazovky | slabý |
| Nábojnice | ano |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Díky přesnosti je spolehlivý i na delší vzdálenost, kde Uzi a Minigun rozhazují.
- Velká rezerva (300) znamená, že munice skoro nedochází.
- Uzly **Accuracy** jsou u něj téměř zbytečné, lepší jsou **Damage** a **Fire rate** — viz [Strom zbraně](/docs/guns/strom-zbrane).

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 1–3, ale 3 nikdy nepadne.
- Zní stejně jako Pistol — vlastní zvuk chybí.

## Nápady na rozšíření

- Vlastní zvuk výstřelu a přebíjení bubnového zásobníku.
