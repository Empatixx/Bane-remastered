**Revolver** je silnější verze pistole: každá rána ubere 4–5, za cenu pomalejší kadence a menší rezervy.

## Jak to funguje

Poloautomatická zbraň: jedna obyčejná kulka na kliknutí, rozptyl kolem ±5,7°. Má vlastní zvuk výstřelu, přebíjí se zvukem pistole.

## Statistiky

| Vlastnost | Hodnota |
| --- | --- |
| Poškození na ránu | 4–5 (průměr 4,5) |
| Kadence | 2,2 rány/s |
| DPS | 10 |
| Režim | poloautomatická |
| Rozptyl | ±5,7° |
| Zásobník / rezerva | 6 / 60 |
| Přebití | 0,7 s |
| Kritická šance | 0 % |
| Projektil | kulka, střední rychlost, červené světlo |
| Průraz | 0 |
| Otřes obrazovky | střední |
| Nábojnice | ano |
| Munice | krabice s náboji, univerzální krabice |
| Získání | truhla, obchod, hrací automat — [Získávání zbraní](/docs/guns/ziskavani) |

Hodnoty jsou bez vylepšení ze stromu a bez upgradů.

## Tipy a souvislosti

- Díky vyššímu poškození na ránu z něj procentní upgrady poškození (*Sharpened Bullets*, *Dangerous Bullets*) vytěží víc než slabé zbraně.
- Dobře se hodí k mutacím **Deadeye** a **Explosive** — viz [Mutace](/docs/guns/mutace).

## Známé nesrovnalosti

- Stůl se zbraněmi ukazuje poškození 4–6, ale 6 nikdy nepadne.

## Nápady na rozšíření

- Přebíjení po jednom náboji, které jde přerušit.
- „Fan the hammer“ — podržením tlačítka rychle vyprázdní bubínek s větším rozptylem.
