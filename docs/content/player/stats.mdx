## Jak to funguje

Hráč nese komponentu `RunStats`. Systémy do ní zapisují přes `stats::record(world, Stat, amount)`;
statistiky se přenášejí mezi patry (`systems/carry.rs`) a na konci běhu se zpracují.

### Počítadla v běhu (`components/stats.rs` → `RunStats`)

| Pole | `Stat` | Kdy se přičítá |
|------|--------|----------------|
| `fired` | `Fired` | každý výstřel × počet projektilů (brokovnice = počet broků) |
| `hits` | `Hit` | zásah nepřítele **vlastní kulkou** (`DamageSource::Bullet`); ne výbuchy, vyvolané bytosti, mazlíček, jed |
| `kills` + `kills_of[druh]` | `Kill(EnemyKind)` | dohrání death animace nepřítele (ne `Minion`) — počítají se i zabití pastí, mazlíčkem atd. |
| `items` | `Item` | sebrání mince, munice, lektvaru, zbraně ze země i artefaktu |
| `gold` | `Gold` | každá sebraná mince |
| `hurt_this_floor` | `Hurt` | každé volání `hurt` po imunitě (i zásah pohlcený štítem) |
| `untouched_floors` | — | `close_floor`: při odchodu z patra (nebo poražení posledního bosse) +1, pokud `hurt_this_floor == 0` |

### Shrnutí na konci (`summarize`)

Spouští se při smrti, výhře nebo volbě *Die* (`start_death_screen`, jen jednou).

- **Přesnost** = `min(hits, fired) / fired` (0 % pokud se nestřílelo).
- **Odměny** (zlato) — 4 řádky, `growth(floor, faktor, x) = faktor · floor^1,02 · x^1,01` (useknuto):

| Řádek na death screenu | Odměna |
|------------------------|--------|
| Accuracy: N % | `growth(floor, 2, přesnost v %)` |
| Kills: N | `growth(floor, 2, kills)` |
| Loot: N | `growth(floor, 4, items)` |
| Floor: N | `(floor − 1) · 5` |

Příklad: patro 3, 60 % přesnost, 40 zabití, 20 předmětů → 383 + 254 + 252 + 10 = 899 zlata.

Výsledek se zapíše do profilu (`Profile::record_run`) a vyhodnotí mise a výzva (`finish_run`) — dokončená
výzva přičte talenty. Případná poznámka („mise splněna“ apod.) se ukáže na death screenu.

### Doživotní statistiky profilu (`profile.rs` → `Profile`)

| Pole | Význam |
|------|--------|
| `gold`, `total_earned` | aktuální a celkově vydělané zlato |
| `balance` | talenty (měna pro [talenty](/docs/player/upgrades)) |
| `runs`, `wins`, `deaths` | počty běhů |
| `kills`, `items_collected` | součty |
| `bullets_fired`, `bullets_hit` | součty (hit omezen na fired) |
| `best_floor` | nejhlubší patro |

### Death screen (`systems/death_screen.rs`)

Lebka vyjíždí 2,5 s, pak titulek, pak 4 řádky po 0,5 s (ikona + popisek + „+N“ zlata, které se načítá),
blikající výzva k pokračování; jakákoli klávesa po dokončení animace vrátí hráče do lobby.

## Interakce

- Mise měří `kills`, `kills_of`, patro, `gold`, `items` a `untouched_floors` — viz [Průběh hry a progrese](/docs/progression).
- Zlato se utrácí za stromy vylepšení zbraní — [Zbraně](/docs/guns).

## Kde v kódu

- `components/stats.rs` → `RunStats`
- `systems/stats.rs` → `Stat`, `record`, `close_floor`, `current`, `Summary`, `summarize`, `growth`
- `systems/death_screen.rs` → `DeathScreen`, `update_death_ui`
- `scenes/ingame.rs` → `start_death_screen`, `next_floor`
- `profile.rs` → `Profile::record_run`, `SharedProfile::finish_run`
- `progress/missions.rs` → `Goal::measure`

## Jak přidat novou statistiku

1. Přidej pole do `RunStats` a variantu do `enum Stat`; doplň větev v `record`.
2. Zavolej `stats::record(world, Stat::Nova, n)` v systému, kde událost nastává.
3. Má-li být doživotní, přidej pole do `Profile` (je `serde(default)`, staré profily se načtou) a přičti v `record_run`.
4. Má-li dávat odměnu, rozšiř `Summary.rewards` (dnes pevné pole 4) a `DeathScreen::label` / `ROWS`.
5. Pro misi přidej `Goal` / `GoalKind` a větev v `measure` (`progress/missions.rs`).

## Nápady / chybí

- Neexistuje obrazovka se statistikami profilu — `Profile` je sbírá, ale hráč je nikde nevidí (kromě počítadel talentů a zlata v lobby).
- `Hurt` se počítá i při zásahu pohlceném štítem (viz [Model poškození](/docs/player/damage)).
- Patro, na kterém hráč zemře, se do `untouched_floors` nepočítá (`close_floor` se volá jen při sestupu a při poražení posledního bosse).
- Chybí statistiky: čas běhu, počet úhybů, nejvyšší zásah, zabití bossů zvlášť (jen přes `kills_of`), utracené mince.
- Přesnost penalizuje brokovnice (každý broček je „výstřel“).
