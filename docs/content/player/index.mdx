In Bane you control a single character, a lone shooter who descends floor by floor into a procedurally generated dungeon.
The character has no levels or experience. Power comes from weapons, artefacts, items picked up during the run and permanent
talents bought in the lobby.

## How it works

### Starting values

| Property | At the start of a run | Note |
|-----------|-----------------|----------|
| Health | **12** | base 10, the talent *Hero's Heart* (+20%) is always yours for free; with *Titan's Heart* 15 |
| Armor | **5** | with *Improved Armor* 6 |
| Walking speed | about **7 tiles per second** | base ~6.4 tiles/s, the talent *Swiftwind Steps* (+10%) is free |
| Dodge speed | about 12 tiles per second | neither talents nor surfaces change it |
| Invulnerability after a hit | 1 s | |
| "Low health" warning | below 30% of max health | a sound signal and pulsing red screen edges |
| Weapon slots | 2 (Pistol + Shotgun) | with the talent *Additional Gun* 3 |
| Artefact | Reveal Map | one slot, activated with the F key |
| Coins | 0 | |
| Weapon damage | **+20%** | the talent *Sharpened Bullets* is free |

The character casts a warm light around itself, so you can see your nearest surroundings even in dark rooms.

### How a run goes

1. **Start** — you step into the portal in the lobby. The game sets the rules based on the chosen challenge, builds the first
   floor and recalculates your health and armor from the talents you own.
2. **Every floor** — talents are applied again (weapon slots, ammo capacity, any challenge limits). If
   you have the talent *Pet*, a pet appears next to you.
3. **Playing** — you clear rooms, collect items, shop and look for the stairs down.
4. **Descent** — you carry health, armor, coins, weapons, artefact and run stats to the next floor.
   **Health does not recover between floors.**
5. **End** — when health drops to 0, when you win, or when you choose *Die* in the pause menu. Then comes the final
   screen with a summary and a gold reward, and you return to the lobby.

<Callout type="info">
The character has no passive health regeneration. You can only restore it with potions, some artefacts, and armor also with the
talent *Armor Regeneration* (+1 armor per cleared room).
</Callout>

## Known inconsistencies

- The first talent of every tree is free, so the player always has +10% speed, +20% health and +20% damage.
  You never see the "bare" base values of the character (10 health, lower speed) in the game.
- Older descriptions of the game say the character has no dodge — in the current version a dodge exists (see [Movement and dodge](/docs/player/movement-dodge)).

## Ideas for expansion

- A choice of several characters with different starting stats, unlocked through meta-progression.
- In-run upgrades ("boons" after clearing a room, Hades style).
- Make the first nodes of the talent trees cost something, so the base character is really basic.
