Bane is played with keyboard and mouse: the keys move you and perform actions, the mouse aims and shoots.
You can rebind most keys in the settings.

## How it works

### Rebindable actions

| Action | Default key |
|------|-----------------|
| Move up (Move up) | W |
| Move down (Move down) | S |
| Move left (Move left) | A |
| Move right (Move right) | D |
| Interact (Interact) | E |
| Reload (Reload) | R |
| Artefact (Artefact) | F |
| Drop gun (Drop gun) | Q |
| Map (Map) | Tab |
| Dodge (Dodge) | Space |

Moving diagonally is not faster than moving straight.

### Fixed controls

| Input | Action |
|-------|-------|
| Mouse | aiming; the camera shifts slightly toward the cursor |
| Left mouse button | shooting (automatic weapons while held, others on every click) |
| Mouse wheel | next / previous weapon |
| 1–9 | direct choice of a weapon slot |
| Esc | pause; closes the big map and the talent menu |

In the talent menu and on the big map you move the canvas with the movement keys or by dragging the mouse.

### Rebinding

- In the settings, click an action's row and press a new key. Changes take effect after you press *Apply*.
  You can open the settings from the main menu and from the pause menu (Esc → Settings), so you can change keys even in the middle of a run.
- You can assign the letters A–Z, arrows, Space, Tab, Enter, left Shift, Ctrl and Alt. Esc, digits (reserved for
  weapon slots) and F-keys cannot be assigned.
- If you choose a key that another action already uses, the two actions **swap** keys — two actions on one key
  never happen.
- The labels on objects ("Press E to …") and the hint at the weapon table ("Drag or WASD …") always show
  the keys you currently have set — they change right after rebinding.
- Key settings are saved together with the other game settings. If the saved file is corrupted, the keys
  return to the defaults.

## Known inconsistencies

- Esc and the mouse buttons cannot be rebound.

## Ideas for expansion

- Gamepad support.
- The option to rebind shooting, weapon switching and slots 1–9 too.
- Use the right mouse button (e.g. for the dodge or the artefact).
- A "hold / toggle" option and an aim sensitivity setting.
