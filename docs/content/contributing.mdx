## Running it

```bash
cd docs
pnpm install
pnpm dev        # http://localhost:3000/docs
pnpm build      # checks that all MDX pages compile
```

## Structure

- `docs/content/<topic>/` — one folder per topic (`guns`, `enemies`, …).
- `index.mdx` — overview of the topic; the other `.mdx` files are subpages.
- `meta.json` — the folder name in the menu, the icon ([lucide](https://lucide.dev/icons)) and the page order.
- Other files in `docs/` (`app/`, `lib/`, `components/`) are the Fumadocs app — you do not need to change them for content.

## Page template

```mdx
---
title: Name
description: One sentence.
---

Short intro: what it is and what role it plays in the game.

## How it works
## Stats
## Contents
## Tips and connections
## Known inconsistencies
## Ideas for expansion
```

## MDX rules

- Less-than signs and curly braces in text break the build — write them in words ("less than").
- Components: `<Callout type="info|warn|error">`, `<Cards>` + `<Card title href />`.
- Write like a game wiki, not code documentation: no file names, types or variable names.
- The wiki is written in simple English. Every page must stay in English.
- Links between pages: `/docs/<topic>/<page>`.
- When you change values in the game (damage, HP, prices), update the matching table here too.
